## ✅ Scope of Work

All AI coding tasks, code edits, file creation, and refactoring are
**exclusively scoped to** the `bible-college-website` folder.

## Project Overview

**Institute of Christian Studies (ICS)** — a NATA-accredited theological college
website in Vijayawada, Andhra Pradesh.

- **Framework**: TanStack Start (React 19 + Vite 8 + Nitro SSR)
- **Styling**: Tailwind CSS v4 with custom design tokens (`src/styles.css`)
- **Routing**: TanStack Router (file-based, `src/routes/`)
- **UI Library**: shadcn/ui (Radix primitives, `src/components/ui/`)
- **Package manager**: `bun` (use `bun install`, `bun run dev`, `bun run build`)
- **Deployment**: Cloudflare (via Lovable, auto-synced from `main` branch)

## Key Rules

1. **Do NOT touch** `src/routeTree.gen.ts` — auto-generated by TanStack Router.
2. **Do NOT touch** `src/lib/error-capture.ts`, `error-page.ts`, `lovable-error-reporting.ts` — Lovable error plumbing, must remain intact.
3. **Do NOT force-push, rebase, amend, or squash** commits already pushed — Lovable syncs from git history.
4. **All design tokens** (colors, fonts, radii) live in `src/styles.css` — do not add arbitrary hex/rgb values to components.
5. **Use `cn()` from `src/lib/utils.ts`** for all conditional className merging.
6. **Run `bun run build`** after every set of changes to confirm zero TypeScript errors before finishing.
